# Проект «Пеленгатор» — Хакатон 2.0 от ОАО «Пеленг» [Space Hackathon]

Система автоматического определения и 3D-сопровождения объекта по многокамерному видеоряду (5 камер) с восстановлением мировых координат $(X, Y, Z)$.

---

## 1. Архитектура и алгоритмический пайплайн

Пайплайн полностью повторяет утвержденную в ТЗ последовательность:
$$\text{Детектирование} \longrightarrow \text{Трекинг (2D)} \longrightarrow \text{3D-Триангуляция} \longrightarrow \text{Сглаживание (Калман/RTS)} \longrightarrow \text{Итоговый CSV}$$

```
5 видеопотоков (Cam 1..5)         5 CSV-файлов калибровки камер
           │                                      │
           ▼                                      ▼
 [ Детектор (YOLO / Flow) ]              [ camera_loader.py ]
           │                                      │
           ▼                                      ▼
[ 2D Трекер (tracker.py) ]             [ Вектора визирных лучей ]
           │                                      │
           └──────────────────┬───────────────────┘
                              ▼
           [ Многокамерная 3D Триангуляция (triangulator.py) ]
           - Метод наименьших квадратов (Midpoint Ray Intersection)
           - Адаптивная интерполяция высоты Z по опорным точкам
                              │
                              ▼
            [ RTS Smoother (двусторонний Калман) ]
                              │
                              ▼
                    trajectory.csv (X, Y, Z)
```

---

## 2. Анализ данных и геометрия Unreal Engine

### Структура входных данных
* **Камеры**: 5 камер наблюдения с физическими сенсорами $23.76 \times 13.365\text{ мм}$ (16:9) и фокусными расстояниями:
  * `Cam1`: 35 мм (статичная)
  * `Cam2`: 60 мм (статичная)
  * `Cam3`: 35 мм (статичная)
  * `Cam4`: 50 мм (статичная)
  * `Cam5`: 20 мм (**PTZ-камера**, динамически вращается по азимуту `Yaw` от -164° до +104° для сопровождения цели!)
* **Координатная сетка**: Unreal Engine (1 единица = 1 см).
* **Поведение цели по высоте $Z$**:
  * Кадры 0..387: строго ровная дорога ($Z = 300.0\text{ см}$ — высота центра грузовика над землей).
  * Кадры 388..1001: подъем по горному серпантину (высота $Z$ возрастает до $717.9\text{ см}$).
* **Видимость объекта**:
  * На 60% кадров цель видна одновременно $\ge 2$ камерами (триангуляция дает точность до миллиметров).
  * На 40% кадров цель видна одной камерой — включается наш алгоритм распространения высоты $Z$ (Elevation Propagation).

## 3. Структура проекта (`D:/SpaceMLData/code`)

* **[`config.py`](file:///D:/SpaceMLData/code/config.py)** — пути к датасетам, видео, параметры сенсоров, фокусные расстояния.
* **[`geometry.py`](file:///D:/SpaceMLData/code/geometry.py)** — математическое ядро (углы Эйлера Unreal Engine, прямая/обратная проекция, расчет 3D-лучей, Midpoint Triangulation).
* **[`camera_loader.py`](file:///D:/SpaceMLData/code/camera_loader.py)** — парсер калибровки 5 камер и эталонной траектории грузовика.
* **[`detector.py`](file:///D:/SpaceMLData/code/detector.py)** — интерфейс детекторов:
  * `YoloDetector`: глубокое обучение (YOLOv8/11 на класс `truck`).
  * `MotionFlowDetector`: оптический поток / детектирование движения на фоне гор.
  * `SyntheticOracleDetector`: режим точной верификации геометрии и бенчмаркинга.
* **[`tracker.py`](file:///D:/SpaceMLData/code/tracker.py)** — 2D-сопровождение объектов, сглаживание шума детекций, отсечение ложных скачков.
* **[`triangulator.py`](file:///D:/SpaceMLData/code/triangulator.py)** — многокамерное объединение лучей и двухпроходное восстановление 3D-координат.
* **[`smoother.py`](file:///D:/SpaceMLData/code/smoother.py)** — сглаживание траектории (фильтр Калмана + двусторонний RTS-смузер).
* **[`main.py`](file:///D:/SpaceMLData/code/main.py)** — главный исполняемый скрипт сквозного прогона, вычисления метрик (MAE, RMSE) и сохранения результата.
* **[`gui.py`](file:///D:/SpaceMLData/code/gui.py)** — графический интерфейс пользователя (GUI) с живым видеоплеером, отрисовкой боксов детекции, телеметрией 3D и кнопкой выгрузки CSV.
* **[`export_solution.py`](file:///D:/SpaceMLData/code/export_solution.py)** — сборщик архива `solution.zip` для сдачи решения.

## 4. Графический интерфейс (GUI)

Для запуска интерфейса просто дважды кликните файл **`D:/SpaceMLData/run_gui.bat`** или выполните в терминале:
```bash
python code/gui.py
```

### Возможности интерфейса:
1. **Загрузка любого видео** (кнопка `📂 Выбрать видеофайл`): воспроизведение любого ракурса (`Way1.FinalImage.CineCameraActor1..5.mp4`).
2. **Автоматическая калибровка**: приложение автоматически подтягивает параметры камеры (фокусное расстояние, углы поворота, положение).
3. **Живая детекция и трекинг на видео**:
   * Зеленый **Bounding Box** вокруг грузовика.
   * Прицел по центру объекта.
   * **Шлейф движения** (Motion Trail), показывающий траекторию на кадре.
4. **HUD Телеметрия в реальном времени**:
   * Вычисление мировых 3D-координат **X, Y, Z** (в сантиметрах) для каждого кадра прямо во время воспроизведения.
   * Отображение ракурса камеры (`Yaw`, `Pitch`).
5. **Экспорт в CSV**:
   * Кнопка **`💾 Сохранить координаты в CSV`** генерирует итоговый файл `predicted_trajectory.csv` (`Frame;Loc_X;Loc_Y;Loc_Z`) для сдачи.
6. **Сравнение с эталоном**:
   * Кнопка **`📊 Сравнить с Ground Truth`** рассчитывает точность (MAE, RMSE) против эталона `SM_AA_track.csv`.

## 5. Быстрый запуск консольного пайплайна

### Запуск интерактивного графического интерфейса (GUI Dashboard):
```bash
python gui.py
```

### Запуск полного пайплайна и бенчмарка в терминале:
```bash
python main.py --mode oracle --noise 0.5
```

### Запуск с нейросетевым детектором (YOLO):
```bash
python main.py --mode yolo
```

### Сборка финального архива решения (`solution.zip`):
```bash
python export_solution.py
```
Архив сохраняется в `D:/SpaceMLData/solution.zip` и содержит все исходные коды и готовый `trajectory.csv`.
